2. ИДЕЯ
================================================================================

Featherpeak Fury — офлайн-мобильное приложение для подготовки к пешим
походам, прогулкам в горах и другим маршрутам с физической нагрузкой.

Пользователь вводит основные параметры будущего маршрута:

• длину;

• набор высоты;

• предполагаемую продолжительность;

• тип поверхности;

• вес рюкзака;

• количество участников;

• запас еды;

• предполагаемые расходы.

После этого приложение локально обрабатывает введённые данные и формирует
единый профиль поездки.

Пользователь получает:

• оценку сложности;

• визуальный профиль маршрута;

• расчёт нагрузки рюкзака;

• рекомендуемый запас питания;

• ориентировочный бюджет;

• список потенциально сложных участков;

• компактную карточку поездки;

• локальную историю сохранённых маршрутов.

Главная особенность Featherpeak Fury заключается в объединении нескольких
разрозненных подготовительных расчётов в одной визуальной системе.

Вместо отдельных несвязанных калькуляторов приложение использует структуру:

Peak
↓
Feather
↓
Egg
↓
Coin

Peak отвечает за профиль и сложность маршрута.

Feather отвечает за нагрузку и распределение веса.

Egg используется как визуальная единица запаса питания.

Coin используется как визуальная единица бюджета и расходов.

Курицы, яйца и монетки являются частью фирменной визуальной системы
приложения. Они не создают игровые механики, не являются наградами и не
используются для соревнований или прогрессии.

6. ОСНОВНОЙ ПОЛЬЗОВАТЕЛЬСКИЙ ПРОЦЕСС
================================================================================

1. Пользователь запускает приложение.

2. При первом запуске знакомится с основной системой.

3. Создаёт новую поездку.

4. Вводит название и параметры маршрута.

5. Добавляет длину и набор высоты.

6. Указывает предполагаемую продолжительность.

7. Выбирает тип поверхности.

8. Добавляет вес рюкзака и основные категории снаряжения.

9. Указывает количество участников.

10. Получает локальный расчёт сложности.

11. Открывает Peak Profile.

12. Проверяет распределение нагрузки через Feather Load.

13. Проверяет рекомендуемый запас питания через EggPack.

14. Добавляет предполагаемые расходы в CoinBudget.

15. Просматривает Fury Zones.

16. Открывает итоговую Offline Trip Card.

17. Сохраняет маршрут локально.

18. При повторном использовании открывает маршрут из архива.

19. При необходимости изменяет параметры и получает обновлённый расчёт.

7. ОСНОВНЫЕ МЕХАНИКИ ПРИЛОЖЕНИЯ
================================================================================

АНАЛИЗ МАРШРУТА

Главная функциональная механика приложения.

Пользователь вводит основные характеристики маршрута:

• расстояние;

• набор высоты;

• продолжительность;

• тип поверхности;

• переносимую нагрузку.

На основе этих параметров приложение рассчитывает условную итоговую
сложность.

Результат должен быть понятным и не перегруженным техническими данными.

Например, итоговая оценка может разделяться на:

• лёгкий;

• умеренный;

• сложный;

• очень сложный.

Оценка используется как ориентир для подготовки, а не как профессиональная
медицинская или спасательная оценка.


-------------------------------------------------------------------------------

PEAK PROFILE

Peak Profile представляет параметры маршрута в виде понятного визуального
профиля.

Профиль показывает основные условные участки:

• подъём;

• спуск;

• ровная поверхность;

• продолжительный сложный участок.

Пользователь может быстро увидеть, где концентрируется основная нагрузка.

Главная польза функции заключается в том, что маршрут воспринимается не
только как набор чисел.


-------------------------------------------------------------------------------

FEATHER LOAD

Feather Load предназначен для оценки нагрузки рюкзака.

Пользователь добавляет предметы по категориям:

• вода;

• питание;

• одежда;

• аптечка;

• оборудование;

• электроника;

• прочее.

Приложение суммирует вес и показывает распределение между категориями.

Дополнительно система может выделять слишком тяжёлые категории.

Курица и перья используются как тематические визуальные элементы раздела,
но не влияют на расчёты.


-------------------------------------------------------------------------------

EGGPACK

EggPack рассчитывает ориентировочный запас питания.

Пользователь указывает:

• продолжительность;

• количество участников;

• интенсивность маршрута.

Приложение формирует рекомендуемый объём условных единиц питания.

Яйца используются как визуальное представление Egg Units.

Например:

1 Egg Unit = одна условная порция запаса питания.

Точное содержимое питания пользователь определяет самостоятельно.

Это позволяет использовать функцию для разных видов продуктов.


-------------------------------------------------------------------------------

COINBUDGET

CoinBudget предназначен для локального расчёта бюджета.

Пользователь может добавлять расходы по категориям:

• транспорт;

• питание;

• парковка;

• снаряжение;

• дополнительные расходы.

Приложение показывает:

• сумму по каждой категории;

• общую сумму;

• распределение расходов.

Монетки используются исключительно как тематический визуальный символ
бюджета.


-------------------------------------------------------------------------------

FURY ZONES

Fury Zones определяет потенциально сложные части маршрута.

К ним могут относиться:

• большой набор высоты;

• продолжительный подъём;

• высокая общая нагрузка;

• тяжёлый рюкзак;

• длинная продолжительность;

• сложная поверхность.

Система не запрещает пользователю маршрут.

Она визуально выделяет параметры, на которые следует обратить внимание
при подготовке.


-------------------------------------------------------------------------------

OFFLINE TRIP CARD

Offline Trip Card объединяет основную информацию о поездке в одной
компактной карточке.

Карточка содержит:

• название маршрута;

• расстояние;

• набор высоты;

• продолжительность;

• оценку сложности;

• объём воды;

• условный запас питания;

• общий вес рюкзака;

• общий бюджет;

• основные Fury Zones.

Карточка доступна локально без подключения к интернету.


-------------------------------------------------------------------------------

TRIP ARCHIVE

Trip Archive хранит подготовленные маршруты локально.

Пользователь может:

• открыть ранее созданную поездку;

• посмотреть основные параметры;

• изменить данные;

• пересчитать маршрут;

• удалить ненужную запись.

Архив позволяет повторно использовать подготовленные шаблоны.

БАЛАНС СЛОЖНОСТИ МАРШРУТА

Оценка не должна резко переходить к максимальной сложности из-за одного
единственного параметра.

Итоговый результат строится по нескольким группам факторов:

1. Расстояние.

2. Набор высоты.

3. Продолжительность.

4. Тип поверхности.

5. Вес нагрузки.

Каждый фактор имеет собственный вклад.

Пример логики распределения:

• расстояние — 25%;

• набор высоты — 30%;

• продолжительность — 15%;

• тип поверхности — 10%;

• вес рюкзака — 20%.

Итоговая оценка:

0–25:
Лёгкий маршрут.

26–50:
Умеренный маршрут.

51–75:
Сложный маршрут.

76–100:
Очень сложный маршрут.

Максимальный уровень не должен назначаться только из-за одной категории,
если остальные параметры остаются минимальными.


-------------------------------------------------------------------------------

БАЛАНС ПИТАНИЯ

Расчёт EggPack зависит от:

• продолжительности;

• количества участников;

• интенсивности.

Длительность является основным фактором.

Количество участников увеличивает общий запас линейно.

Высокая интенсивность добавляет дополнительный резерв.

Пример логики:

Базовый запас:
1 условная порция на участника за базовый временной блок.

Умеренная нагрузка:
базовое значение.

Высокая нагрузка:
базовое значение + 20%.

Очень высокая нагрузка:
базовое значение + 35%.

Это позволяет не завышать запас при коротких и лёгких маршрутах.


-------------------------------------------------------------------------------

БАЛАНС НАГРУЗКИ

Feather Load показывает общий вес и распределение категорий.

Основная цель системы — выявлять дисбаланс, а не запрещать пользователю
брать определённый вес.

Например:

Нормально:
вес равномерно распределён между необходимыми категориями.

Внимание:
одна категория занимает непропорционально большую часть веса.

Высокая нагрузка:
несколько тяжёлых категорий одновременно.

Система должна объяснять причину предупреждения.


-------------------------------------------------------------------------------

БАЛАНС ПРЕДУПРЕЖДЕНИЙ

Предупреждения не должны появляться слишком часто.

Принцип:

• один заметный фактор — мягкое информационное уведомление;

• два серьёзных фактора — предупреждение;

• три и более серьёзных факторов — выраженное выделение Fury Zone.

Это предотвращает ситуацию, при которой приложение постоянно показывает
предупреждения и снижает их полезность.


-------------------------------------------------------------------------------

БАЛАНС ИНТЕРФЕЙСА

На одном экране не должно одновременно отображаться слишком много
показателей.

Приоритет информации:

1. Главный результат.

2. Ключевые параметры.

3. Предупреждения.

4. Детализация.

Пользователь должен видеть основной результат сразу, а подробные данные
открывать при необходимости.

18. ОГРАНИЧЕНИЯ И СЦЕНАРИИ НЕДОСТАТОЧНЫХ ДАННЫХ

Если пользователь ввёл недостаточно параметров:

• приложение показывает, каких данных не хватает;

предварительную оценку.

Если отсутствует набор высоты или тип поверхности, приложение сообщает,
что итоговая оценка может быть менее точной.

Если не введены расходы:

CoinBudget показывает отсутствие данных, а не выдумывает бюджет.

Если не введён вес предметов:

Feather Load показывает неполный расчёт.

19. ИТОГ
================================================================================

Featherpeak Fury («Пернатая Вершина») — офлайн-мобильное приложение для
подготовки к пешим маршрутам, прогулкам и поездкам с физической нагрузкой.

Приложение объединяет анализ сложности маршрута, визуальный профиль,
расчёт веса рюкзака, условный расчёт запаса питания, бюджет и выявление
потенциально сложных зон.

Главная функциональная особенность заключается в единой системе:

Peak — маршрут и сложность.

Feather — нагрузка.

Egg — запас питания.

Coin — бюджет.

Курицы, яйца и монетки присутствуют как тематическая часть визуального
языка продукта и не создают игровых механик.

Все основные действия выполняются локально на устройстве.

Приложение не требует:

• интернета;

• аккаунта;

• сервера;

• внешних API;

• постоянного подключения.

Структура из 12 экранов позволяет небольшой команде реализовать полноценный
продукт без сложной инфраструктуры.

Сбалансированная система расчётов постепенно повышает детализацию:
пользователь может получить быстрый базовый результат или заполнить
полный набор параметров для более подробной подготовки.

Premium Outdoor Utility визуальный стиль, простой вертикальный интерфейс,
локальное хранение и единая тематическая система делают Featherpeak Fury
цельным офлайн-приложением с потенциалом дальнейшего расширения без
изменения его основной концепции.
